Calibração do Motor Probabilístico

Ajuste a importância de cada variável no cálculo de influência e risco de perda.

Peso da Credibilidade da Fonte (Wcred) 35%

Fontes oficiais (Copom, CVM, Fed) têm impacto mais persistente que rumores especulativos.

Peso da Intensidade de Sentimento (Wsent) 35%

Mede a força direcional (euforia ou pânico) capaz de movimentar preços no curto prazo.

Peso do Impacto Macroeconômico / Setorial (Wmacro) 30%

Avalia abrangência sistêmica (juros, câmbio, commodities, regulação) para posições semanais/mensais.

Normalização automática aplicada na fórmula: Soma Bruta: 100% (Normalizado = 1.00)

Fórmulas Transparentes do Modelo

1. Índice de Influência da Notícia (IIN)
IIN = (0.35 × Cred) + (0.35 × |Sent|) + (0.30 × Macro)
2. Probabilidade Ajustada de Perda (PAP)
PAP = Clamp(ProbBase × 1.00 × (1.35 - IIN/200), 5%, 92%)

Autenticação Pessoal (Supabase Auth — Opcional) Modo Workspace (sem login)
Passo 1: Cole este SQL no "SQL Editor" do Supabase e clique em Run 
create table if not exists public.pulsequant_workspaces (
  workspace_id text primary key,
  user_id uuid references auth.users(id) on delete set null,
  payload jsonb not null,
  updated_at timestamptz not null default now()
);

alter table public.pulsequant_workspaces
  add column if not exists user_id uuid references auth.users(id) on delete set null;

alter table public.pulsequant_workspaces enable row level security;

drop policy if exists "Acesso por workspace_id" on public.pulsequant_workspaces;
create policy "Acesso por workspace_id ou usuario autenticado"
  on public.pulsequant_workspaces
  for all
  to anon, authenticated
  using (user_id is null or auth.uid() = user_id)
  with check (user_id is null or auth.uid() = user_id);
